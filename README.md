## 🇺🇦 Компетенції та Досвід (Ukrainian)

### 🖥 Апаратне забезпечення та діагностика (Hardware & Diagnostics)
- **Компонентна діагностика:** Виявлення апаратних несправностей (відвал сокета/чіпсета, вихід з ладу ланцюгів живлення відеокарт та материнських плат).
- **Стрес-тестування та моніторинг:** Використання середовищ завантаження WinPE (Sergei Strelec) для запуску AIDA64, OCCT та MemTest86. Аналіз температурних режимів та стабільності системи під навантаженням.
- **Модернізація та обслуговування (Maintenance):** Заміна жорстких дисків (HDD на SSD), підбір та встановлення оперативної пам'яті (RAM), заміна блоків живлення (PSU). Повне фізичне очищення системних блоків та заміна термоінтерфейсів.
- **Конфігурація BIOS/UEFI:** Налаштування таймінгів та частот оперативної пам'яті (JEDEC/XMP) при використанні різних модулів. Ручне виділення відеопам'яті (VRAM) для інтегрованої графіки. Управління станами Secure Boot та активація модуля TPM 2.0 для подальшого апаратного шифрування (BitLocker/VeraCrypt).

### 🐧 Адміністрування ОС (Windows / Linux)
- **Розгортання Windows:** Встановлення ОС з підготовлених WIM/ESD образів. Встановлення пропрієтарних драйверів, створення локальних профілів користувачів, налаштування локалізації та інтерфейсу.
- **Linux-адміністрування:** Встановлення, налаштування та розв'язання апаратних конфліктів у дистрибутивах (CachyOS, Linux Mint, Lubuntu, KDE Neon).
- **Скриптинг та Автоматизація (Bash / PowerShell):**
  - Розробка скриптів для автоматизованого створення локальних користувачів (генерація безпечних паролів, обмеження прав доступу, заборона привілеїв адміністратора).
  - Написання інтерактивних скриптів для апаратної інвентаризації (Hardware Inventory). Скрипт через CLI збирає детальні метрики ПК (включно з EDID-даними підключених моніторів) та експортує звіт у текстовий файл з прив'язкою до ПІБ співробітника.

### 🌐 Мережева інфраструктура та Віддалена підтримка
- **Мережеві протоколи:** Розуміння принципів маршрутизації, роботи служб DNS (доменні імена) та DHCP (динамічний розподіл IP-адрес).
- **Діагностика мережі:** Використання CLI-утиліт (ping, tracert) та сканерів безпеки (`Nmap`, `Zenmap`) для аналізу топології мережі та перевірки відкритих портів.
- **Віддалене управління:** Адміністрування Linux-серверів по протоколу SSH. Використання протоколів безпечної передачі даних SCP/SFTP.
- **Helpdesk (L1/L2):** Надання віддаленої підтримки користувачам (AnyDesk, RDP). Траблшутинг проблем з підключенням до мережі, цілісністю драйверів та програмним забезпеченням.

### 🖨 Оргтехніка та Принт-сервери
- **Обслуговування периферії:** Заміна тонер-картриджів, усунення механічних застрягань паперу, налаштування сканерів.
- **Мережевий друк (TCP/IP Printing):** Налаштування принтерів та МФП з вбудованим мережевим інтерфейсом. Призначення статичних IP-адрес, розгортання драйверів на клієнтських робочих станціях.
- **Кастомні принт-сервери на базі OpenWrt:** Прошивка маршрутизаторів (TP-Link) на альтернативну ОС OpenWrt по SSH. Налаштування мережевих інтерфейсів та розгортання пакетів принт-сервера (CUPS / p910nd) для інтеграції USB-принтерів та принтерів етикеток у локальну бездротову мережу.
