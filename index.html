Налаштування ПК та заміна комплектуючих PC Setup & Component Replacement

L0 | HARDWARE DIAGNOSTICS
SSD • RAM • MEMTEST86 • OCCT • THERMAL PASTE

Апаратна діагностика, заміна компонентів, тестування стабільності та підготовка системи до роботи. Hardware diagnostics, component replacement, stability testing, and system preparation for operation.

1 Апаратна діагностика Hardware Diagnostics

Для налаштування потрібно перевірити саме залізо: відкрити кришку корпусу, почистити від пилу та, якщо потрібно, поміняти термопасту на процесорі. Перевіряємо всі з'єднання та кабелі. To set up the system, inspect the hardware: open the case, clean out dust, and replace thermal paste on the CPU if necessary. Check all connections and cables.

2 Тестування компонентів Component Testing

Після фізичної перевірки запускаємо тести для перевірки стабільності роботи ОЗП та процесора. Для ОЗП використовуємо MemTest86 (мінімум 2 проходи), для CPU — OCCT або AIDA64 System Stability Test (графік Throttling має бути 0%). After the physical inspection, run tests to check RAM and CPU stability. Use MemTest86 for RAM (minimum 2 passes), and OCCT or AIDA64 System Stability Test for CPU (Throttling graph must be 0%).

Обслуговування принтерів та МФУ Printer & MFP Maintenance

L0 | PRINTERS & SCANNERS
CARTRIDGES • MFP • TCP/IP • DRIVERS

Заміна картриджів, усунення заторів паперу, налаштування мережевих принтерів та МФУ. Cartridge replacement, paper jam removal, network printer and MFP configuration.

1 Заміна картриджа Cartridge Replacement

Заміна картриджа проходить дуже швидко: відкриваємо кришку принтера, виймаємо старий картридж, знаходимо такий самий уже заповнений, встановлюємо в принтер та закриваємо кришку. Cartridge replacement is very quick: open the printer cover, remove the old cartridge, find a matching filled one, install it in the printer, and close the cover.

⚠

Важливо:Important: Картридж від HP не підійде до принтера Canon і навпаки. Завжди перевіряйте сумісність виробників та моделей перед заміною! A cartridge from HP will not fit a Canon printer and vice versa. Always check manufacturer and model compatibility before replacement!

2 Усунення затору паперу Paper Jam Removal

Якщо в принтері застряг папір: вимикаємо принтер, відкриваємо кришку та обережно витягуємо папір. Іноді потрібно дістати картридж перед вилученням паперу. Після усунення затору — перевіряємо друк. If paper is jammed in the printer: turn off the printer, open the cover, and carefully remove the paper. Sometimes you need to remove the cartridge before extracting the paper. After clearing the jam, test a print.

3 Налаштування мережевого принтера Network Printer Setup

Для підключення та налаштування мережевого принтера потрібно встановити відповідний драйвер через офіційний сайт виробника, після чого додати принтер у Windows. To connect and set up a network printer, install the appropriate driver from the official manufacturer website, then add the printer in Windows.
