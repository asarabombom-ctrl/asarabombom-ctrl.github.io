Практичні рішення (SOP)

Автоматизація інвентаризації (CLI)

Розробка скрипта для збору телеметрії ПК. Скрипт через WMI збирає дані про процесор, диски та оперативну пам'ять, а також парсить EDID для точної ідентифікації моніторів. Експорт звітів у .txt за ПІБ користувача.

OpenWrt Принт-сервери

Інтеграція USB-принтерів та принтерів етикеток у бездротову мережу. Прошивка роутерів (TP-Link) по SSH (root@192.168.1.1), конфігурація статики та розгортання пакетів p910nd для друку по порту 9100.

User Provisioning

Скрипти генерації робочих місць: автоматичне створення профілю, генерація надійного пароля та жорстке обмеження прав (виключення з групи Адміністраторів для дотримання політики PoLP).

Етап 1 | 0–6 міс.

IT Technician

>

Апаратне забезпечення (Hardware)

  • Обслуговування ПК, заміна SSD/RAM/БП, кабель-менеджмент[cite: 1].
  • Глибока чистка систем охолодження, заміна термоінтерфейсів, діагностика ланцюгів живлення.

Діагностика & Тестування

  • Використання WinPE (Sergei Strelec) для роботи з мертвими ОС.
  • Пошук помилок пам'яті через MemTest86.
  • Стрес-тестування процесорів та моніторинг температур у AIDA64 / OCCT.

BIOS / UEFI Конфігурація

  • Вимкнення Secure Boot для Linux та застарілого ПО.
  • Синхронізація частот RAM за стандартами JEDEC або увімкнення XMP.
  • Увімкнення TPM 2.0 (підготовка до шифрування BitLocker).
  • Ручне виділення відеопам'яті (VRAM) для інтегрованої графіки.

Оргтехніка (Периферія)

  • Базове обслуговування принтерів та МФУ[cite: 1].
  • Заміна картриджів, тонерів, безпечне усунення механічних застрягань паперу[cite: 1].
Етап 2 | 6–12 міс. | ПОТОЧНИЙ РІВЕНЬ

Helpdesk / IT Support

>

Підтримка користувачів (L1/L2)

  • Обробка інцидентів та заявок, віддалене управління через AnyDesk / RDP[cite: 1].
  • Траблшутинг ПЗ, діагностика відсутності мережі (перевірка кабелів, пінг, перезавантаження роутерів).

Мережі & Інфраструктура

  • Розуміння принципів роботи DNS (імена) та DHCP (автоматичний IP).
  • Сканування локальних мереж, перевірка портів утилітами Nmap та Zenmap.
  • Налаштування мережевого друку, створення принт-серверів на OpenWrt.

Операційні системи

  • Чисте встановлення Windows з підготовлених WIM/ESD образів, розгортання драйверів.
  • Встановлення та адміністрування Linux (CachyOS, Mint, Lubuntu, Arch). Робота з терміналом.

Скриптинг & Інвентаризація

  • Автоматизація рутини через Bash та PowerShell (створення користувачів, збір метрик апаратного забезпечення)[cite: 1].
