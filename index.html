Установка Windows / Linux (Ventoy) Windows / Linux Installation (Ventoy)

Інструкція з підготовки завантажувального носія та розгортання ОС. Instructions for bootable media preparation and OS deployment.

1. Підготовка флешки 1. USB Flash Drive Preparation

Встановлюємо Ventoy на флешку 16/32 Gb, закидаємо ISO-образи Windows або відповідний дистрибутив Linux. Install Ventoy on a 16/32 Gb USB flash drive, copy Windows ISO images or a suitable Linux distribution.

2. Процес встановлення 2. Installation Process

Вставляємо флешку в ПК/ноутбук, вибираємо UEFI-диск у Boot menu, обираємо потрібний ISO та встановлюємо систему. Insert the USB into the PC/laptop, select the UEFI drive in the Boot menu, choose the required ISO, and install the system.

Настройка ПК, замена комплектующих PC Setup & Component Replacement

Апаратна профілактика та програмна настройка робочих місць. Hardware maintenance and workstation software configuration.

1. Апаратна ревізія 1. Hardware Audit

Відкриваємо кришку, чистимо від пилу, змінюємо термопасту, тестуємо пам'ять через MemoryTest. Open the casing, clean dust, replace thermal paste, and test memory via MemoryTest.

2. Налаштування середовища 2. Environment Setup

Ставимо OS, перевіряємо драйвери, створюємо користувача через скрипт PowerShell, інсталюємо софт, підключаємо облікові записи та принтери. Install OS, check drivers, create a user via PowerShell script, install software, connect accounts and printers.

Обслуживание принтеров и МФУ Printers & MFPs Maintenance

Робота з картриджами, заминами паперу та мережевою печаткою. Working with cartridges, paper jams, and network printing.

1. Заміна картриджів 1. Cartridge Replacement

Відкриваємо кришку, виймаємо старий картридж, ставимо заправлений аналогічний. Враховуємо несумісність брендів (напр. HP і Canon). Open the cover, remove the old cartridge, insert a refilled equivalent. Consider brand incompatibility (e.g., HP and Canon).

2. Замять паперу та сетева настройка 2. Paper Jams & Network Setup

Вимикаємо принтер, акуратно витягуємо папір. Для підключення: ставимо драйвер, в Windows додаємо принтер за IP (192.168.хх.хх). Turn off the printer, carefully pull out the paper. To connect: install the driver, in Windows add the printer by IP (192.168.xx.xx).

Работа с пользователями и удалёнка User Support & Remote Access

Використання засобів віддаленого адміністрування. Using remote administration tools.

1. Алгоритм підтримки 1. Support Workflow

Використовуємо AnyDesk або TeamViewer. Спочатку вислуховуємо проблему, після чого підключаємося та вирішуємо її безпосередньо з робочого місця. Use AnyDesk or TeamViewer. First listen to the problem, then connect and solve it right from your workstation.

Инвентаризация оборудования Equipment Inventory

Автоматизований облік техніки та її ревізія. Automated equipment tracking and auditing.

1. PowerShell скрипт інвентаризації 1. PowerShell Inventory Script

Скрипт запитує ПІБ співробітника, генерує текстовий файл з інформацією про залізо (модель, серійні номери, комплектуючі, монітори) для бази. The script asks for the employee's name, generates a text file with hardware info (model, serial numbers, components, monitors) for the database.

# Принцип роботи скрипта інвентаризації / Inventory script logic
$name = Read-Host "Введіть Ім'я Прізвище"
$info = Get-ComputerInfo ... # збір даних про ПК / PC data collection
$info | Out-File "C:\Inventory\$name.txt"

2. Ревізія фонду 2. Reserve Fund Audit

Невикористані ПК/ноутбуки чистяться, обслуговуються (термопаста), тестуються, оснащуються відповідною під потужність OS та додаються в базу. Unused PCs/laptops are cleaned, serviced (thermal paste), tested, equipped with an appropriate OS, and added to the database.
