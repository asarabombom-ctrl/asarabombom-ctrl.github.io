⚙️ Standard Operating Procedures (SOP)

Апаратна підготовка (Hardware)

  • Обслуговування: Повне очищення, перевірка ланцюгів живлення, заміна термопасти.
  • BIOS/UEFI: Вимкнення Secure Boot, ручне виділення VRAM, увімкнення TPM 2.0 для BitLocker.
  • Тестування: WinPE (Sergei Strelec), MemTest86, стрес-тести AIDA64.

Бездротові принт-сервери (OpenWrt)

  • Прошивка: Встановлення OpenWrt на роутери (TP-Link) через SSH.
  • Конфігурація: Призначення статичної IP-адреси та пакетів p910nd / CUPS.
  • Мережа: Інтеграція USB-принтерів етикеток у Wi-Fi мережу підприємства.

Автоматизація (Bash / PowerShell)

  • Користувачі: Скрипти генерації профілів без прав адміністратора.
  • Інвентаризація: CLI-утиліта для збору WMI-метрик (RAM, CPU, диски).
  • Периферія: Зчитування EDID-даних моніторів з експортом у `.txt`.

🚀 Дорожня карта розвитку (IT Roadmap)

IT Technician

0–6 місяців

ПК, ноутбуки, принтери, картриджі, МФУ, кабелі, периферія. Базова діагностика та ремонт апаратного забезпечення.

Helpdesk / IT Support (Поточний)

6–12 місяців

Робота з користувачами, розгортання Windows/Linux, віддалена допомога (AnyDesk/RDP), обробка заявок та скриптова інвентаризація.

Junior System Administrator

1–2 роки (Наступний крок)

Windows Server, Active Directory, DNS, DHCP, системи резервного копіювання, маршрутизація та базові мережі.

System Administrator

2–3 роки

Сервери, налаштування MikroTik, VPN, VLAN, віртуалізація (Proxmox), Docker, налаштування систем моніторингу.
