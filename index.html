🖥 Апаратне забезпечення та Діагностика

[ ДОСВІД ЗДОБУТО - Клікни для деталей ]
Базове та компонентне обслуговування системних блоків і ноутбуків.
  • Діагностика: Використання середовища WinPE (Sergei Strelec). Перевірка цілісності оперативної пам'яті через MemTest86, стрес-тестування процесорів та моніторинг температур у AIDA64 / OCCT.
  • BIOS/UEFI: Ручна синхронізація частот RAM за стандартами JEDEC. Активація TPM 2.0 для подальшого шифрування дисків. Ручне виділення VRAM.
  • Апгрейд: Заміна HDD на SSD, встановлення ОЗП, заміна блоків живлення, нанесення термоінтерфейсів та кабель-менеджмент.

🐧 Автоматизація ОС та Скриптинг

[ ДОСВІД ЗДОБУТО - Клікни для деталей ]
Розгортання Windows та Linux-дистрибутивів, написання Bash/PowerShell скриптів.
  • Розгортання: Встановлення Windows з WIM-образів, налаштування локалізації та драйверів. Досвід роботи з дистрибутивами CachyOS, Linux Mint, KDE Neon.
  • User Provisioning: Написання скриптів для автоматичної генерації безпечних паролів та створення локальних користувачів із суворим обмеженням прав (PoLP - видалення з групи Адміністраторів).
  • Hardware Inventory: CLI-скрипти для автоматичного збору WMI-метрик (RAM, CPU, накопичувачі) та парсинг EDID-даних моніторів з експортом у .txt звіти.

🖨 Мережі, Helpdesk та Принт-сервери

[ ПОТОЧНА РОБОТА - Клікни для деталей ]
Підтримка користувачів, робота з SSH та нестандартні рішення для оргтехніки.
  • OpenWrt Інженерія: Перепрошивка маршрутизаторів TP-Link по SSH. Налаштування пакетів p910nd / CUPS для створення бездротових принт-серверів для старих USB-принтерів та принтерів етикеток.

  • Helpdesk: Віддалене вирішення інцидентів через AnyDesk/RDP. Траблшутинг відсутності інтернету (роутери, драйвери, кабелі).
