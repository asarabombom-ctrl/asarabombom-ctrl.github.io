В процесі
В планах
IT Technician

Апаратне забезпечення ПК

  • Обслуговування: Очищення від пилу, перевірка контактів, заміна термопасти та комплектуючих (SSD/RAM/БЖ).
  • BIOS/UEFI: Вимкнення Secure Boot, налаштування TPM 2.0 (BitLocker), виділення VRAM, JEDEC синхронізація.
  • Тестування: WinPE (Sergei Strelec), діагностика RAM (MemTest86), стрес-тести CPU (AIDA64, OCCT).
IT Technician

Периферія та Оргтехніка

  • Базове обслуговування: Заміна тонерів, картриджів, усунення застрягань паперу.
  • Мережевий друк: Налаштування IP-адрес для принтерів/сканерів з LAN-портом, розгортання драйверів на клієнтських ПК.
Helpdesk / IT Support

Віддалена підтримка & Мережі

  • Підтримка користувачів: Робота через AnyDesk/RDP. Траблшутинг відсутності підключення (перевірка кабелів, роутерів).
  • Мережева діагностика: Розуміння роботи DNS та DHCP. Сканування мереж утилітами Nmap та Zenmap, перевірка пінгу та маршрутів.
Engineering

Принт-сервери на OpenWrt

  • Прошивка: Встановлення OpenWrt на роутери (TP-Link) через SSH (root@192.168.1.1).
  • Конфігурація: Налаштування статичного IP, підключення до Wi-Fi.
  • Пакети: Встановлення p910nd / CUPS. Прокидання TCP порту 9100 для USB-принтерів та принтерів етикеток.
Helpdesk / SysAdmin

ОС та Скриптинг (Автоматизація)

  • Розгортання ОС: Windows (з образів WIM), Linux (CachyOS, Lubuntu, KDE Neon).
  • Скрипт користувачів: Автогенерація локальних профілів з паролями без прав Адміністратора (PoLP).
  • Скрипт інвентаризації: Збір WMI-даних (CPU, RAM, диски) та EDID-даних моніторів. Експорт у іменні .txt файли.
Junior Sysadmin (1-2 роки)

Windows Server & Інфраструктура

  • Розгортання Active Directory (AD DS).
  • Управління правами доступу через Group Policy (GPO).
  • Налаштування корпоративних DNS та DHCP серверів.
  • Системи резервного копіювання (Backup & Recovery).
System Administrator (2-3 роки)

Віртуалізація та Мережева Безпека

  • Гіпервізори: Proxmox VE, VMware ESXi.
  • Контейнеризація: базове адміністрування Docker.
  • Мережі: Налаштування VLAN, маршрутизація, VPN-тунелі.
  • Обладнання: Адміністрування фаєрволів (MikroTik RouterOS).
