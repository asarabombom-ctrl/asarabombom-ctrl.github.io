Standard Operating Procedures (Технічні інструкції)

🖥 1. Апаратна діагностика та підготовка ПК (Hardware Provisioning)

Мета: Стандартизоване тестування, ремонт та підготовка робочих станцій до видачі користувачу.

  • Фізичне обслуговування: Повне очищення від пилу, перевірка підключення шлейфів. Заміна термопасти. Тестування контактів дискретної відеокарти та оперативної пам'яті.
  • Конфігурація BIOS/UEFI: Вимкнення Secure Boot (для сумісності з Linux/застарілим ПЗ). Синхронізація частот оперативної пам'яті за стандартами JEDEC при використанні різних плашок. Ручне виділення VRAM для інтегрованої графіки. Увімкнення TPM 2.0 для шифрування дисків.
  • Стрес-тест та діагностика: Завантаження з WinPE (Sergei Strelec). Використання MemTest86 для пошуку битих секторів пам'яті. Запуск AIDA64 / OCCT для стрес-тесту процесора та моніторингу троттлінгу температур.
  • Розгортання ОС: На актуальне залізо — встановлення Windows із підготовленого образу. Для старих ПК — легковісні дистрибутиви Linux (Lubuntu, Linux Mint) для офісних задач. Оновлення драйверів, створення профілю користувача.

🖨 2. Створення бездротових принт-серверів (OpenWrt)

Мета: Інтеграція звичайних USB-принтерів та принтерів етикеток у локальну мережу без використання виділеного ПК.

  • Підготовка маршрутизатора: Скидання роутера (наприклад, TP-Link) до заводських налаштувань. Підключення по SSH за стандартною адресою root@192.168.1.1.
  • Прошивка: Встановлення альтернативної ОС OpenWrt на маршрутизатор.
  • Налаштування мережі: Задання статичної IP-адреси роутеру (наприклад, 192.168.1.2) та підключення його до основної Wi-Fi мережі у режимі клієнта.
  • Конфігурація принт-сервера: Встановлення пакетів для підтримки USB-друку (kmod-usb-printer, p910nd). Прокидання TCP порту 9100.
  • Підключення клієнтів: На робочих ПК додавання принтера через "Standard TCP/IP Port", вказавши статичний IP роутера. Встановлення драйверів.

📜 3. Автоматизація рутини (Bash / PowerShell Скриптинг)

Мета: Мінімізація людського фактора при обліку обладнання та налаштуванні прав доступу.

  • Скрипт створення користувачів: Автоматично генерує безпечний пароль, створює локальний профіль. Критичний крок: скрипт примусово видаляє користувача з групи Адміністраторів для запобігання несанкціонованим змінам у системі.
  • Інтерактивний скрипт інвентаризації (Hardware Inventory): При запуску запитує ПІБ співробітника. Звертається до WMI для збору точних даних (серійні номери, обсяг RAM, процесор).
  • Облік периферії: Скрипт зчитує EDID-дані моніторів, щоб визначити їх точну модель та діагональ. Всі дані експортуються у персоналізований `.txt` файл для бази даних IT-відділу.

🌐 4. Мережева інфраструктура та Віддалена підтримка

Мета: Забезпечення безперебійної роботи мережі та швидке вирішення інцидентів (L1/L2 Helpdesk).

  • Віддалена підтримка: Підключення через AnyDesk. Траблшутинг при відсутності інтернету: перевірка фізичного кабелю, перезавантаження роутера, перевірка доступності вузлів через `ping`, діагностика цілісності мережевих драйверів.
  • Мережева діагностика: Використання Nmap / Zenmap для сканування топології мережі та пошуку відкритих портів. Розуміння та діагностика протоколів DNS (роздільна здатність імен) та DHCP (розподіл IP).
  • Linux / SSH: Підключення до серверів та ноутбуків на базі Linux (CachyOS) через SSH. Використання скриптів для тонкої оптимізації системи під конкретне залізо. Безпечна передача файлів.
