L0: Апаратна діагностика та BIOS L0: Hardware Diagnostics & BIOS

Алгоритм дій при налаштуванні та діагностиці проблемного заліза.

1. Виділення VRAM для APU (напр. AMD A8-5600K)

Якщо інтегрована графіка (Radeon HD 7560D) працює повільно, необхідно вручну виділити пам'ять в BIOS, оскільки автоматичне виділення часто дає збої.

1. Зайти в BIOS (Del / F2) -> Розділ "Advanced" або "Chipset"
2. Знайти параметр "UMA Frame Buffer Size" або "Share Memory"
3. Змінити значення з Auto на 2G (2048MB) при наявності 16GB RAM.
4. Зберегти налаштування (F10).

2. Тестування ОЗП (RAM) та CPU

При BSOD `MEMORY_MANAGEMENT`: завантаження з USB у WinPE → запуск MemTest86 (мінімум 2 проходи). Для стрес-тесту процесора використовується OCCT або AIDA64 System Stability Test (графік Throttling має бути 0%).

L1: Адміністрування Windows & PowerShell L1: Windows Administration & PowerShell

Автоматизація первинного налаштування робочих станцій.

1. Скрипт Provisioning.ps1

Написання власного адміністративного скрипта для швидкої підготовки ПК до роботи.

# Обхід політики виконання скриптів
Set-ExecutionPolicy Bypass -Scope Process -Force

# Вимкнення телеметрії та непотрібних служб
Stop-Service -Name "DiagTrack" -Force
Set-Service -Name "DiagTrack" -StartupType Disabled

# Налаштування базової мережі (IPv4)
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.50 -PrefixLength 24 -DefaultGateway 192.168.1.1

2. Права NTFS vs Share Permissions

Правило: Share Permissions завжди ставимо "Everyone -> Full Control". Увесь реальний захист налаштовується виключно на вкладці Security (NTFS).

L2: Архітектура Linux (Arch/CachyOS) L2: Linux Architecture (Arch/CachyOS)

Траблшутинг системних сервісів у дистрибутивах на базі Arch Linux.

1. Налаштування аудіо (PipeWire)

Заміна застарілого PulseAudio на сучасний PipeWire для вирішення проблем зі звуком.

# Встановлення необхідних пакетів (pacman)
sudo pacman -S pipewire pipewire-pulse pipewire-alsa wireplumber

# Активація сервісу від імені користувача
systemctl --user enable --now pipewire pipewire-pulse wireplumber

2. Відновлення роботи Bluetooth

sudo pacman -S bluez bluez-utils
sudo systemctl enable bluetooth.service
sudo systemctl start bluetooth.service
# Підключення через термінал
bluetoothctl -> power on -> scan on -> pair [MAC] -> connect [MAC]

L3: Мережева Інфраструктура (OpenWrt & CUPS) L3: Network Infrastructure (OpenWrt & CUPS)

Інструкція з перетворення звичайного USB-принтера на мережевий пристрій за допомогою роутера (напр. TP-Link TL-MR3020) на базі OpenWrt.

1. Підключення та прошивка по SSH

# Підключення до роутера та оновлення пакетів

# Встановлення драйверів для USB принтера та CUPS сервера

2. Налаштування клієнтських ПК (Windows)

В "Пристрої та принтери" додайте принтер через "Standard TCP/IP Port". Вкажіть статичний IP вашого OpenWrt роутера. Протокол: RAW, порт 9100.

L6: Автоматизація (Python & aiogram) L6: Automation (Python & aiogram)

Розробка асинхронних Telegram-ботів на Python для автоматизації взаємодії (на прикладі інтеграції з DuckDuckGo Search та MongoDB).

import asyncio
from aiogram import Bot, Dispatcher, types
from motor.motor_asyncio import AsyncIOMotorClient

# Налаштування MongoDB (motor)
cluster = AsyncIOMotorClient("mongodb://localhost:27017")
db = cluster["bot_database"]
users_collection = db["users"]

# Ініціалізація aiogram бота
bot = Bot(token="YOUR_BOT_TOKEN")
dp = Dispatcher(bot)

@dp.message_handler(commands=['start'])
async def send_welcome(message: types.Message):
    await message.reply("Вітаю! Я бот-асистент.")

if __name__ == '__main__':
    asyncio.run(dp.start_polling())

L7: Кібербезпека (Nmap & Auditing) L7: Cybersecurity (Nmap & Auditing)

Сканування мережі для виявлення вразливостей та відкритих портів (спеціальність 125).

1. Команди Nmap для аудиту мережі

# Швидке сканування локальної підмережі на наявність активних хостів
nmap -sn 192.168.1.0/24

# Агресивне сканування цілі (визначення ОС, версій сервісів, трасування)
nmap -A -T4 192.168.1.50

# Пошук конкретних вразливостей за допомогою Nmap Scripting Engine (NSE)
nmap --script vuln 192.168.1.50
