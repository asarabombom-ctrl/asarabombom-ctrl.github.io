TECHNICAL GUIDES (SOP)

База знань: покрокові інструкції з налаштування обладнання, мереж та автоматизації.

01. Бездротовий принт-сервер (OpenWrt)

Інструкція з перетворення звичайного USB-принтера або принтера етикеток на повноцінний мережевий пристрій за допомогою роутера (напр., TP-Link).

Крок 1. Підключення та прошивка по SSH

Скиньте роутер до заводських налаштувань. Підключіться через термінал по SSH та встановіть прошивку OpenWrt.

# Підключення до стокового роутера
ssh root@192.168.1.1
# Після авторизації виконайте прошивку (sysupgrade)

Крок 2. Налаштування мережі та пакетів

Призначте роутеру статичний IP у вашій основній підмережі (напр. 192.168.1.2) та підключіть його до Wi-Fi як клієнт. Після цього встановіть необхідні пакети для підтримки USB-друку.

opkg update
opkg install kmod-usb-printer p910nd luci-app-p910nd

Крок 3. Налаштування клієнтських ПК (Windows)

На робочих станціях перейдіть у "Пристрої та принтери" -> "Додати принтер". Оберіть "Додати за допомогою TCP/IP адреси".

Вкажіть статичний IP роутера (192.168.1.2). Тип пристрою: Custom. Переконайтесь, що використовується протокол RAW та порт 9100. Далі встановіть стандартний драйвер виробника.

02. Апаратне розгортання та Діагностика (Provisioning)

Стандартний алгоритм підготовки робочих станцій перед видачею співробітникам або після ремонту.

Стрес-тести та діагностика

Завантажте систему із USB-накопичувача з WinPE (Sergei Strelec).

1. Запустіть MemTest86 для перевірки ОЗП на биті сектори.
2. Запустіть AIDA64 або OCCT (вкладка System Stability Test). Навантажте CPU та FPU мінімум на 15 хвилин. Слідкуйте за графіком CPU Throttling — він має залишатись на рівні 0%.

Конфігурація BIOS/UEFI

Перед встановленням ОС (особливо корпоративних Windows з шифруванням або Linux):

1. Secure Boot -> Disabled (для сумісності з кастомними образами)
2. Security Device Support (TPM 2.0) -> Enabled (обов'язково для BitLocker)
3. UMA Frame Buffer Size -> Виставити вручну (напр. 2G) для інтегрованої графіки
4. DRAM Timing -> JEDEC/Auto (якщо плашки ОЗП від різних виробників)

03. Скриптинг: Інвентаризація та Користувачі (Bash/PS)

Алгоритми мінімізації людського фактора під час базового адміністрування.

Автоматична інвентаризація (Hardware Inventory)

Скрипт через WMI (Windows Management Instrumentation) запитує серійні номери та характеристики. Для моніторів використовується парсинг реєстру (EDID).

# Приклад логіки PowerShell для WMI
Get-WmiObject Win32_Processor | Select-Object Name, NumberOfCores
Get-WmiObject Win32_PhysicalMemory | Measure-Object -Property Capacity -Sum

Створення користувачів (PoLP)

Принцип найменших привілеїв (Principle of Least Privilege). Скрипт генерує профіль, пароль і жорстко контролює групи.

# Обов'язкова перевірка виключення з групи Адміністраторів
Remove-LocalGroupMember -Group "Administrators" -Member "UserName"
